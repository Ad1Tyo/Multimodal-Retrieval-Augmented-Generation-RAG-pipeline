# Multimodal-Retrieval-Augmented-Generation-RAG-pipeline
A multimodal Retrieval-Augmented Generation (RAG) pipeline using LangChain and the Unstructured library. 
An AI-powered system that can query complex documents, such as PDFs containing text, images, tables, and plots by setting up the Unstructured library to parse and pre-process various document formats, from images to text.
